Продовжуємо «Agent Content Factory». Зараз робимо «фабрику контенту»: єдиний бренд-контекст, автоматичні чернетки, контроль витрат та розумнішу зв'язку.

Зроби:

1. Профіль проєкту. Додай таблицю project_profile (один рядок: бізнес, аудиторія, продукти, тон, табу, приклади). Створи src/profile.ts, який перед кожним запитом до Claude (і в чаті, і в прогоні) домішує профіль до характеру агента. На дашборді — сторінка «Профіль» для редагування.

2. Замкнута петля. Додай таблиці content_plan (що і коли публікуємо на майданчиках: YouTube, Telegram, Instagram) та content_drafts (чернетки). Коли власник схвалює завдання-публікацію — результат автоматично стає чернеткою і потрапляє в контент-план. Додай сторінки «Календар» (/calendar) та «Завдання» (/tasks). Сторінка «Завдання» має виглядати як і мати функціонал як Канбан борда, де завдання переходять і можна пересувати по статусу виконання.

3. Контроль витрат. Додай у таблиці runs та tasks поля вартості та токенів; рахуй і показуй витрати на завдання та на прогін; дай можливість задати опціональний бюджет на прогін.

4. Розумніша зв'язка: залежності між завданнями (завдання чекає на результати іншого), уточнювальні запитання агента до власника зі статусом waiting_question, таймаути на кожного агента та ретрай планування.

5. Контроль власника: редагування плану (редагування/видалення/перепризначення завдань), запуск прогону прямо з чату зі Стратегом, кнопка «повторити прогін», кнопки «копіювати» біля результатів.

6. Перед хмарою: опціональний пароль на дашборд (змінна SWARM_PASSWORD — якщо порожня, авторизацію вимкнено) та команда npm run db:backup (дамп бази в папку backups/, зберігає останні 14).

Онови базу через npm run db:migrate, запусти проєкт, перевір профіль, бюджет та автостворення чернетки після схвалення. Наприкінці прогони npm run typecheck.
