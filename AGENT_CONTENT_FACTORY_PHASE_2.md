Все 8 агентів як собесідники

Продовжуємо «Agent Content Factory». Зараз додамо решту агентів, щоб із кожним можна було листуватися віч-на-віч через розділ «Чати».

Зроби:

1. Додай у db/seed.sql ще 7 агентів, у кожного свій характер (системний промпт російською, своя «особистість» та зона відповідальності):
   - Сценарист — пише сценарії для відео, рілсів та постів.
   - Рілсмейкер — придумує короткі вертикальні відео.
   - Монтажер — відповідає за монтаж і збірку відео.
   - Дизайнер — візуальне пакування: обкладинки, прев'ю, брифи.
   - Публікатор — стратегія та оформлення публікацій.
   - Програміст — допомагає розуміти та лагодити систему рою.
   - Критик — перевіряє роботу агентів на помилки та галюцинації.
   Усі is_active = TRUE. Промпти зроби живими та різними за тоном.

2. У бекенді створи реєстр чату: src/agents/handlers.ts — зіставляє slug агента з обробником. Усі агенти в режимі чату використовують спільний conversational.ts, особистість береться із системного промпту в базі.

3. На дашборді:
   - Сторінка «Чати» (/chats) — список усіх 8 агентів картками. (Реалізовано, але перевір)
   - Сторінка чату з конкретным агентом (/chats/[agentId]) — листування з історією, красиво оформлені повідомлення (markdown).
   - Додай розділ «Чати» в бічне меню. (Вроді реалізовано, але перевір)

4. Онови дані агентів у базі командою npm run db:seed (вона не повинна стирати історію чатів). Запусти проєкт і перевір, що з усіма 8 агентами можна листуватися і кожен відповідає у своєму характері. Прогони npm run typecheck.

Нагадай мені: характери агентів живуть у db/seed.sql (не в коді), і будь-який характер можна потім переписати там же і знову запустити npm run db:seed.
