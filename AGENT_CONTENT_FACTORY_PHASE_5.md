Продовжуємо «Agent Content Factory». Це великий крок — перетворюємо систему на platform для кількох каналів одразу. Роби частинами й звіряйся зі мною.

Зроби:

1. Мультипроєкти. Створи таблицю projects і прив'яжи до проєкту все: прогони, чати, завдання, контент-план, профіль, знання. Створи перший демопроєкт. Верхня навігація: «Проєкти», «Інбокс ідей», «Акаунт». Усередині проєкту — бічне меню: Огляд, Прогони, На перевірці, Календар, Завдання, Чати, Профіль, Знання, Тести.

2. Прямі завдання агентам. У чаті з кожним агентом — кнопка «Поставити завдання» (solo, оминаючи планування), «Делегувати Стратегу» та «Запустити прогін рою».

3. База знань. Таблиці knowledge_sources та knowledge_chunks (повнотекстовий пошук через tsvector). Матеріали проєкту (наприклад, папка експортованих нотаток) індексуються, і релевантні шматки домішуються в системні промпти агентів у чаті та в прогоні. Сторінка «Знання» з кнопкою «Запустити інгест» та CLI-команда npm run knowledge:ingest -- --dir=/шлях.

4. Двосторонній Telegram. Бекенд через long-polling приймає повідомлення від власника та маршрутизує: Стратегу за замовчуванням, конкретному агенту (/agent slug …), ставить завдання (/task …), збирає ідеї (/idea …), перемикає проєкт (/project slug). Публикація в канал — POST /api/content-plan/:id/publish/telegram або кнопка в Календарі (chat_id каналу — в профілі проєкту).

5. Фабрика тестів. Таблиці test_scenarios (типові сценарії по всіх агентах) та test_runs. Команда npm run tests:seed завантажує сценарії, npm run tests:batch -- --limit=30 проганяє їх через Критика та пише вердикти. Сторінка «Тести» — зведення якості: пас-рейт по агентах, вартість, тривалість.

6. Інбокс ідей. Таблиця idea_inbox та сторінка: ідею можна закинути через Telegram (/idea …) і одним кліком перетворити на прогін.

Оновлюй базу через npm run db:migrate по ходу справи, запускай проєкт і перевіряй кожну частину окремо. Наприкінці прогони npm run typecheck та npm run tests:batch.
