# Agent Content Factory — Пам'ятка проєкту

## Опис проєкту
Ми будуємо **Agent Content Factory** — систему автономного ведення соціальних мереж, яка складається з 8 ШІ-агентів.

## Стек технологій
- **Архітектура:** Монорепозиторій на базі npm workspaces
- **Дашборд (Фронтенд):** Next.js + React + Tailwind CSS
- **Бекенд:** Node.js + Express + tsx (TypeScript Execute)
- **База даних:** PostgreSQL
- **Агенти:** Claude Agent SDK

## Важливі правила розробки
- **Конфігурація та безпека:** Усі чутливі дані, токени та ключі доступу зберігаються **виключно у файлі `.env`** у корені проєкту. Цей файл внесено до `.gitignore` і він ніколи не повинен потрапляти до репозиторію.
- **Структура репозиторію:**
  - `apps/` — додатки (зокрема фронтенд дашборду)
  - `packages/` — спільні бібліотеки та SDK агентів
  - `db/` — схеми даних, міграції та скрипти бази даних
